# Development Notes

This directory contains meta-documentation used during the development process. These files are **not** required for deployment or end-user usage.

## Contents

### Conversation & Continuity
- **CONVERSATION_CONTINUITY.md** - Context for resuming AI-assisted development sessions
- **ENVIRONMENT_NOTES.md** - Venus OS constraints and development learnings

### Phase Documentation
- **PHASE1_SUMMARY.md** - Phase 1 (BLE parsing) completion summary
- **PHASE1_VALIDATION_COMPLETE.md** - Phase 1 validation results
- **PHASE2_PLAN.md** - Phase 2 (D-Bus integration) planning notes

### Setup Guides
- **GITHUB_SETUP.md** - Initial GitHub repository setup instructions

## Purpose

These files serve as:
1. **Context** for AI assistants continuing development
2. **History** of development decisions and discoveries
3. **Reference** for environment constraints and patterns

## Not Included in Release

These files are excluded from:
- Deployment tarballs (`govee-ble-deploy.tar.gz`)
- GitHub releases
- End-user documentation

If you're continuing development on this project, start by reading:
